# Tasin Kabir — Digital Marketing Portfolio

## Files
- `index.html` — website structure/content
- `style.css` — responsive styling
- `script.js` — mobile navigation, scroll reveal, year

## Before publishing
1. Replace `your.email@example.com` in `index.html` with your real professional email.
2. Replace the LinkedIn URL with your real profile.
3. Replace the placeholder case studies with your actual projects/results.
4. If you want a profile photo, replace the TK circle in the hero with an `<img>` element.
5. Upload all three files to your web host's public/root directory.

No build step is required. It is a plain HTML/CSS/JS website.
